# TechBairro

Sistema de cadastro de clientes desenvolvido em Python.

## Funcionalidades

- cadastrar clientes;
- consultar clientes;
- editar dados dos clientes;
- excluir clientes;
- armazenar informações em um banco de dados SQLite.

## Requisitos

- Python 3 instalado;
- Tkinter, utilizado na interface gráfica;
- SQLite, utilizado para armazenar os dados.

As bibliotecas utilizadas fazem parte da instalação padrão do Python na configuração testada.

## Como executar

1. Extraia o pacote `TechBairro-3.3.1.zip`.
2. Abra um terminal na pasta extraída.
3. Execute:

```bash
python techbairro.py
```

## Banco de dados

O sistema utiliza o SQLite para armazenar os clientes. O arquivo `techbairro.db` é criado automaticamente na pasta do programa quando necessário.

Faça cópias de segurança do banco de dados para evitar a perda dos registros.
